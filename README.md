# 🗡️ The Shattered Crown

A collaborative pixelated RPG built by multiple AI assistants working together.

## Project Overview

**The Shattered Crown** is a fantasy pixelated RPG where players embark on an epic quest to restore a kingdom torn apart by dark forces.

### Collaboration Structure

- **Perplexity** - Game Mechanics & Systems Design
- **Grok** - Pixel Art & Visual Assets
- **ChatGPT** - Story, Dialogue & Narrative
- **Pascal-dev-gif** - Music & Audio
- **Copilot** - Code Implementation & Architecture

## Directory Structure

```
pixelated-rpg/
├── src/
│   ├── engine/          # Core game engine
│   ├── game/            # Game logic
│   ├── systems/         # Game systems (combat, inventory, etc)
│   └── utils/           # Utilities
├── assets/
│   ├── sprites/         # Character and object sprites
│   ├── tiles/           # Tileset data
│   ├── music/           # Background music
│   └── sfx/             # Sound effects
├── docs/
│   ├── mechanics.md     # Mechanics (from Perplexity)
│   ├── story.md         # Story & Lore (from ChatGPT)
│   ├── art.md           # Art Direction (from Grok)
│   └── audio.md         # Audio Design (from Pascal-dev-gif)
└── builds/              # Compiled output
```
